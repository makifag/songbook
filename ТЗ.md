# ТЗ: оффлайн-песенник из закладок (табы + аккорды)

## Задача
Из папки закладок (~51 источник, 8 доменов) собрать **самодостаточный оффлайн-песенник**:
скачать содержимое, вычистить от обвязки сайтов, разложить по исполнителю/игре,
сгенерировать `index.html` с поиском и упаковать всё в `songbook.zip`.
Пользователь распаковывает архив, открывает `index.html` — работает без установки чего-либо.

Максимум автоматизации. Идемпотентно: повторный запуск не перекачивает уже скачанное.
Один вход — `python build.py` — один выход — `songbook.zip` + `report.html`.

## Вход
`sources.json` (прилагается) — уже нормализованный и дедуплицированный список.
Поля каждой записи: `title_raw, url_raw, url_norm, domain, artist, work, handler, status, note`.
- `handler` — какой экстрактор применять.
- `status`: `live` | `dead_wayback` (тянуть из архива) | `manual` (в отчёт, не качать).

Не доверять полю `work` как готовому названию — это slug; человекочитаемое имя брать из шапки страницы.

## Стек и сеть
- Python: `requests` + `beautifulsoup4`(lxml) для статики.
- **amdm.ru рубит датацентр-IP** (бот-защита). Запускать пайплайн с резидентного IP / телефона (Termux).
  Заголовки — как у настоящего браузера (User-Agent, Accept-Language: ru). Если `requests` не проходит —
  фолбэк на Playwright (headless chromium) точечно для amdm.
- **Кэш сырого HTML на диск**: `cache/{sha1(url_norm)}.html`. Перед сетью — проверка кэша (если есть и не старше
  ~30 дней, не качать). Это чтобы итерации по селекторам не били по сети и не ловили бан.
- Рейт-лимит: задержка 1–3 с между запросами к одному домену, ретрай с экспон. бэкоффом (3 попытки).

## Нормализация URL gametabs (правило, если придётся пересчитывать)
- убрать `www.`;
- `/{game}/{song}` → `/tabs/{game}/{song}`;
- `/{platform}/{game}/{song}` → `/tabs/{game}/{song}` (**платформа отбрасывается**);
- уже `/tabs/...` не трогать.
Старые URL (особенно с платформой) отдают **410 Gone** — рабочий только новый вид.
В `sources.json` это уже применено (`url_norm`), но правило зафиксировано на случай новых закладок.

## Хендлеры

### gametabs_ascii (23 шт)
ASCII-таб лежит в код-блоке (`<pre>` / элемент с моноширинным содержимым, где строки идут `E|---0---`).
Взять этот блок как есть (моноширина критична). Дополнительно снять метаданные из шапки:
game, composer, tuning, capo, автор аранжировки, стиль — в шапку песни.
**Бонус (опц., только если задан cookie авторизации):** на странице есть блок "Files" со ссылками
GP `.gp5` / MIDI `.mid` / TXT `.txt` за бесплатным логином. Если в конфиге задан session-cookie —
скачать `.gp5` и `.mid` в `raw/` (для TuxGuitar). Без cookie — только ASCII со страницы, это ок.

### amdm_chords (14 живых)
Аккордник = аккорды строкой над словами. Контейнер с текстом песни (у amdm это блок с классом
вроде `.podbor__text` / `pre#music-text` — уточнить по живой странице). **Сохранять как есть в `<pre>`**,
выравнивание не трогать. Снять тональность/каподастр если указаны.

### dead_wayback — Кино на amdm (6 шт)
Живые страницы удалены («по требованию правообладателя»). Тянуть из Wayback:
1. `GET http://archive.org/wayback/available?url={url_norm}` → `archived_snapshots.closest.url`;
2. фетч снапшота, к архивному HTML применить **тот же amdm_chords-экстрактор** (разметка внутри снапшота та же);
3. снапшота нет → записать в `report` как gap (не падать).

### ultimateguitar_json (1 шт)
Контент не в HTML, а в JSON внутри страницы: `div.js-store[data-content]` — это JSON;
внутри `store.page.data.tab_view.wiki_tab.content` (структуру сверить). Распарсить, вытащить текст,
снять разметку `[tab]...[/tab]`, `[ch]...[/ch]`. Сохранять в `<pre>`.

### mychords_chords / generic_chords (2 шт)
Статика, свой контейнер. Сначала специфичный селектор, при неуверенности —
generic-фолбэк (`trafilatura` / readability): выделить основной текстовый блок, отбросить навигацию/комменты/рекламу.

### songsterr_api / manual_vk / manual_search (5 шт)
Не автоматизировать в первом проходе:
- **songsterr** — таб рисуется JS из данных; ради одной вещи не стоит. В `report` как ручной (можно оставить ссылку).
- **vk** (2 топика + PDF Сеговии) — под авторизацией. В `report` ручными. Для PDF Сеговии — попробовать
  скачать по прямой `doc`-ссылке из `url_raw`; если 200 и это PDF — положить в `raw/`, иначе ручной.
- **greensleeves** — это гугл-поиск, не таб. В `report`: «найти и добавить вручную».

## Экстракция — общий принцип
Специфичный селектор на домен + generic-фолбэк для одиночных сайтов.
Всё, что не таб/аккорды (навигация, комментарии, реклама, «похожее», футер), — выкинуть.
Результат экстракции: `{title, artist, kind: tab|chords, meta:{...}, body:str}`.

## Выход
```
songbook/
  index.html          # самодостаточный: поиск + фильтр (таб/аккорды, исполнитель/игра), список песен
  songs/{slug}.html   # шапка (метаданные) + <pre> с телом; CSS @media print для печати в PDF
  raw/{slug}.txt      # чистое тело (не заперто в HTML)
  raw/{slug}.gp5/.mid # где скачалось с gametabs
  report.html         # что ок / что из Wayback / что ручными / что не нашлось
songbook.zip          # архив всей папки songbook/
```
Требования к HTML:
- **оффлайн**: никаких CDN, всё инлайн (CSS/JS в файлах внутри архива);
- **моноширинный шрифт** для тела (иначе ASCII-табы и аккорды над словами разъедутся);
- поиск и фильтр — на ванильном JS, данные — инлайн JSON в index.html;
- **никакого localStorage** (артефактные ограничения тут ни при чём, просто чтобы открывалось с `file://`);
- печать в PDF — средствами браузера через `@media print` (тёмную тему в печати убирать).

## Идемпотентность
- Кэш HTML (см. выше) → повторный запуск не качает заново.
- `report.html` пересобирается каждый раз.
- Флаг `--refetch` для принудительного обновления кэша.

## Критерии приёмки
1. Все `live`-источники (gametabs / amdm-не-Кино / mychords / gitaristu / UG) — извлечены и в index.
2. 6 Кино — из Wayback либо явный gap в report (не молчаливый пропуск).
3. Табы отображаются моноширинно без съезда строк.
4. Дубли уже схлопнуты в sources.json; две «арии» FFVI — проверить, не 410 ли одна, лишнюю убрать.
5. Повторный запуск без `--refetch` не делает сетевых запросов по уже скачанному.
6. `index.html` открывается по `file://` офлайн, поиск/фильтр работают.
7. На выходе лежит `songbook.zip`.

## Осознанно НЕ делать
- Не конвертировать аккорды amdm в инлайн-ChordPro автоматически — позиции аккордов над буквами
  разъезжаются при парсинге. Хранить как есть в `<pre>`. ChordPro/`.cho` — опциональный экспорт (флаг),
  не блокер приёмки.
- Не логиниться на amdm/vk силой. Cookie — только опционально для gametaps .gp5.
